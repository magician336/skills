# Domain Docs

Engineering skills should read these files before exploring the repository:

- `CONTEXT.md` at the repository root, or `CONTEXT-MAP.md` when multiple contexts exist.
- Relevant decisions under `docs/adr/`.

This repository uses the single-context layout:

```text
/
├── CONTEXT.md
├── docs/adr/
└── skills/
```

Missing context or ADR files should be handled silently. Create them when domain terms or architectural decisions are actually resolved.
